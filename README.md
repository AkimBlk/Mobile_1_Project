# GameGo

Application mobile de découverte de jeux vidéo réalisée en 2e année d'études.

## Description

GameGo est une application Android permettant aux utilisateurs de rechercher et découvrir des jeux vidéo à partir de différentes informations telles que leur titre, leur genre ou leur plateforme.

L'application utilise l'API RAWG pour récupérer les informations sur les jeux et Firebase pour gérer les données et les fonctionnalités liées aux utilisateurs.

## Technologies

- Java
- Android Studio
- Firebase
- RAWG Video Games Database API
- Volley
- Picasso
